Control Center

จัดการเครื่อง คำสั่งเช่า การจ่ายเงิน และเวลาเช่า

ตั้งค่าการชำระเงิน

ใส่ข้อมูลรับเงินได้เอง ระบบตรวจสลิปผ่าน API เมื่อกำหนด SLIP_VERIFY_API_KEY บนเซิร์ฟเวอร์ หากตรวจยอด/ผู้รับ/สลิปซ้ำไม่ผ่าน จะส่งให้แอดมินตรวจสอบ

เพิ่มเครื่องคอมพิวเตอร์

เครื่องและคำสั่งเปิด/ปิด/รีสตาร์ต

คำสั่งจะถูกส่งไปยัง Agent ที่ติดตั้งบนคอมปลายทาง เครื่องที่ปิดสนิทต้องตั้ง Wake-on-LAN เพิ่มจึงจะเปิดได้จากระยะไกล

คำสั่งเช่าและการจ่ายเงิน

ตรวจสอบการรับเงินจริงก่อนกดอนุมัติ ผู้เช่าจะเห็นลิงก์รีโมทหลังคำสั่งได้รับอนุมัติเท่านั้น

การเงิน (รายรับ–รายจ่าย)

ค่าเช่าที่อนุมัติแล้วถูกบันทึกเป็นรายรับอัตโนมัติ • เพิ่มรายรับ/รายจ่ายอื่นได้ภายหลังด้านล่าง
