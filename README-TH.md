# CloudRent — Full-stack starter (ภาษาไทย)

ชุดเริ่มต้นสำหรับพัฒนาเว็บเช่าคอม มีหน้าร้าน, แผงผู้ดูแล, ตั้งค่า QR/บัญชีธนาคาร/TrueMoney Wallet, คำสั่งเช่าตามชั่วโมง, อนุมัติชำระเงิน, คำสั่งเปิด/ปิด/รีสตาร์ตผ่าน Host Agent และช่องเก็บลิงก์รีโมทของแต่ละเครื่อง

> **สำคัญ:** นี่คือ starter ที่ต้องนำไปติดตั้งและตั้งค่าก่อนใช้งานจริง ไม่ใช่ระบบที่ deploy หรือเชื่อมต่อเครื่องคอมของคุณให้แล้ว การชำระเงินเป็นการตรวจสอบโดยแอดมิน ไม่ได้ตรวจยอดเงินอัตโนมัติ ส่วนการรีโมทต้องติดตั้ง/ตั้งค่า Parsec หรือ Sunshine + Moonlight บนเครื่องจริงก่อน

## ต้องมี
- Node.js 20 หรือใหม่กว่า
- เซิร์ฟเวอร์ที่รัน Node.js ได้ (Netlify แบบ static อย่างเดียวรัน `server.js` ไม่ได้)
- คอม Windows ที่คุณเป็นเจ้าของ/ผู้ดูแล สำหรับติดตั้ง Host Agent

## เริ่มทดสอบบนคอม
1. แตก ZIP นี้
2. เปิด Terminal/PowerShell ในโฟลเดอร์โปรเจกต์
3. ติดตั้งแพ็กเกจ: `npm install`
4. คัดลอก `.env.example` เป็น `.env` แล้วเปลี่ยน `ADMIN_PASSWORD`, `JWT_SECRET`, `AGENT_TOKEN` ให้เป็นค่าสุ่มยาว ๆ ห้ามใช้ค่าตัวอย่าง
5. ตั้ง `PUBLIC_BASE_URL` เป็น URL ของ backend
6. รัน `npm start`
7. เปิด `http://localhost:3000`

บัญชีแอดมินจะใช้ค่าจาก `.env` เท่านั้น หากยังไม่ได้เปลี่ยน `ADMIN_PASSWORD` ระบบจะไม่ให้ล็อกอิน

## ช่องทางชำระเงิน
- เข้าผู้ดูแลระบบ → ตั้งค่าการชำระเงิน
- กรอก PromptPay ID, ข้อมูลบัญชีธนาคาร, เบอร์ TrueMoney Wallet และข้อความแนะนำ
- อัปโหลดภาพ QR ที่ถูกต้องและเป็นของบัญชีรับเงินของคุณเอง
- ลูกค้าสร้างคำสั่งและแจ้งเลขอ้างอิง จากนั้นแอดมินต้องตรวจยอดในแอปธนาคาร/Wallet จริงก่อนกด “อนุมัติรับเงิน”
- **อย่าอนุมัติจากภาพสลิปอย่างเดียว** ให้ตรวจยอดเข้าบัญชี/รายการจริง
- หากต้องการตรวจเงินอัตโนมัติ ต้องสมัคร merchant/API กับผู้ให้บริการที่รองรับและเพิ่ม webhook พร้อมตรวจลายเซ็นตามเอกสารทางการของผู้ให้บริการ ไม่ควรเก็บรหัสผ่านบัญชีธนาคารหรือ Wallet ไว้ในเว็บ

## ตั้งค่าเครื่องและรีโมท
1. เพิ่มเครื่องในแผงผู้ดูแล ระบุ ID เช่น `pc-003`, สเปก, ราคา/ชั่วโมง และลิงก์เชื่อมต่อที่ระบบของคุณรองรับ
2. ติดตั้งและตั้งค่า Parsec หรือ Sunshine บน Windows host ตามคู่มือทางการของซอฟต์แวร์นั้น
3. ตั้งค่าตัวแปร Windows ก่อนรัน Agent:
   - `CLOUDRENT_API_BASE` = URL ของ backend เช่น `https://api.example.com`
   - `CLOUDRENT_MACHINE_ID` = ID ที่ตรงกับเครื่องในเว็บ
   - `CLOUDRENT_AGENT_TOKEN` = ค่าเดียวกับ `AGENT_TOKEN` ใน `.env`
4. เปิด PowerShell ในฐานะผู้ดูแลระบบตามความเหมาะสม แล้วรัน `agent/cloudrent-agent.ps1`
5. เมื่อ Agent online จะ heartbeat และรับคำสั่งปิด/รีสตาร์ตจากเว็บ

**ข้อจำกัด:**
- เครื่องที่ปิดอยู่ไม่สามารถรับคำสั่งจาก Agent ได้ ต้องตั้ง Wake-on-LAN ใน BIOS/UEFI, NIC และเครือข่าย และมีอุปกรณ์ที่เปิดอยู่ส่ง magic packet ให้
- การคลิกลิงก์จากเว็บไม่สามารถรับประกันว่าจะเปิดแอป Parsec/Moonlight และเชื่อมต่อให้ทันทีในทุกอุปกรณ์ ต้องใช้ลิงก์/วิธีเชื่อมต่อที่ผู้ให้บริการแอปรองรับและทดสอบกับเครื่องจริง
- ตัวอย่าง Agent นี้ยังไม่จัดการรหัสผ่าน/รหัสเชิญของ session, การจัดสรร GPU, ล้าง session ระหว่างผู้เช่า, ป้องกันผู้เช่าเข้าถึง Windows desktop หลังหมดเวลา หรือการคืนเงินอัตโนมัติ ต้องเพิ่มก่อนเปิดบริการเชิงพาณิชย์
- เวลาสิ้นสุดเช่าถูกบันทึกไว้ แต่ยังต้องเพิ่ม worker ที่ทำงานเบื้องหลังเพื่อจบ session และคืนเครื่องอัตโนมัติใน production

## Deploy
ใช้ VPS หรือแพลตฟอร์มที่รองรับ Node.js + persistent disk/SQLite ได้ อย่าใช้ Netlify static hosting เป็น backend โดยตรง หากต้องการคงหน้าเว็บ Netlify เดิม ให้ deploy backend แยกและตั้งค่า CORS/HTTPS อย่างถูกต้อง (โค้ด starter นี้ยังไม่ได้เปิด CORS ข้ามโดเมนโดยตั้งใจ)

ก่อนเปิดให้ลูกค้า: ใช้ HTTPS, ตั้ง secrets ใหม่, เพิ่ม rate limiting, สำรองฐานข้อมูล, ตรวจ log, ทำระบบยืนยันตัวตนลูกค้า, เพิ่ม CSRF/CORS policy ตามโดเมน, และทดสอบแผนกู้คืนระบบ


## ตรวจสลิปอัตโนมัติ (ตัวเลือก)

1. สมัครบัญชีผู้พัฒนาและรับ API key จาก Thunder Solution: https://developer.thunder.in.th/
2. คัดลอก `.env.example` เป็น `.env` แล้วใส่ `SLIP_VERIFY_API_KEY` ในฝั่งเซิร์ฟเวอร์เท่านั้น ห้ามใส่ API key ใน `public/index.html` หรือแชร์ไฟล์ `.env`
3. API v2 ใช้ตรวจสลิปธนาคาร/พร้อมเพย์ และเปิดการตรวจยอดกับสลิปซ้ำ ส่วนการตรวจ TrueMoney Wallet ใช้ endpoint v1 ตามเอกสารผู้ให้บริการ ซึ่งอาจมีรูปแบบข้อมูลต่างกัน
4. ระบบจะอนุมัติอัตโนมัติเฉพาะเมื่อ API ส่งผลสำเร็จ, ยอดตรง, ไม่ใช่สลิปซ้ำ, มีเลขอ้างอิง และตรวจจับบัญชีผู้รับได้ สำหรับ TrueMoney ต้องตั้งเบอร์ Wallet ในหน้าแอดมินและ API ต้องส่งข้อมูลผู้รับที่จับคู่ได้
5. หาก API ไม่มีข้อมูลที่จำเป็น, ตรวจไม่สำเร็จ, บัญชีผู้รับไม่ตรง หรือเครื่องไม่พร้อม ระบบจะไม่เพิ่มสิทธิ์เช่าและจะให้แอดมินตรวจสอบแทน

ข้อจำกัด: การตรวจสลิปไม่ใช่ API รับเงินโดยตรง และไม่ใช่การยืนยันยอด Wallet แบบ webhook จากผู้ให้บริการชำระเงิน ควรทดลองด้วยบัญชี/รายการทดสอบก่อนเปิดใช้จริง ตรวจสอบแพ็กเกจและความสามารถปัจจุบันของผู้ให้บริการก่อนชำระเงิน


## ระบบการเงิน (แอดมิน → แท็บ "การเงิน")
- **รายรับจากค่าเช่า** ถูกบันทึกอัตโนมัติทุกครั้งที่คำสั่งเช่าได้รับอนุมัติ (ทั้งแอดมินกดอนุมัติและตรวจสลิปผ่านอัตโนมัติ) และจะไม่ถูกบันทึกซ้ำ แก้ไข/ลบไม่ได้เพื่อกันตัวเลขคลาดเคลื่อน
- **เพิ่มรายรับ/รายจ่ายอื่นภายหลังได้ทุกเมื่อ** เช่น ค่าไฟ ค่าเน็ต อะไหล่ ค่าธรรมเนียม คืนเงิน ระบุวันที่ย้อนหลังได้ พิมพ์หมวดหมู่เองได้ แก้ไข/ลบรายการที่บันทึกเองได้
- มีสรุปวันนี้/เดือนนี้/สะสม กราฟ 14 วัน สรุปตามหมวดหมู่ กรองตามช่วงวันที่ และส่งออก CSV (เปิดใน Excel ภาษาไทยได้)
- หากต้องคืนเงินลูกค้า ให้บันทึกเป็นรายจ่ายหมวด "คืนเงิน"
- เวลาในรายงานใช้เขตเวลาไทย (UTC+7)

## สิ่งที่ปรับปรุงจาก starter
- โหลดค่าจาก `.env` ได้จริง (เดิม `npm start` ไม่ได้อ่านไฟล์ .env)
- แอดมินตั้งสถานะเครื่อง "พร้อมเช่า/ออฟไลน์" เอง แก้ราคา/ลิงก์รีโมท และลบเครื่องได้ (ใช้งานได้แม้ยังไม่ติดตั้ง Agent)
- จบการเช่าอัตโนมัติเมื่อครบเวลา (ตรวจทุก 30 วินาที) และคืนเครื่องเป็น "พร้อมเช่า"
- กันอนุมัติ/ปฏิเสธซ้ำ, เทียบรหัสผ่านแบบ constant-time, จำกัดความถี่การล็อกอิน/สั่งเช่า, สุ่ม JWT secret ชั่วคราวถ้าลืมตั้งค่า

> ข้อจำกัดที่ยังต้องทำก่อนเปิดจริง: ระบบยังไม่มีบัญชีลูกค้า (ลูกค้าสั่งเช่าด้วยชื่อเล่น + รหัสคำสั่ง), ยังไม่มีการยืนยันยอดเงินแบบ webhook, และควรสำรองไฟล์ `data/cloudrent.sqlite` เป็นประจำ
